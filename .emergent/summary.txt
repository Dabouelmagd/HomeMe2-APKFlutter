<product_requirements>
The HomeMe application is a management platform for residential compounds, targeting a multilingual user base (English, Arabic, French). The primary product goal is to achieve a fully localized, visually polished, and intuitive user experience, with a strong emphasis on the Arabic interface.

This involves:
1.  **Complete Internationalization (i18n):** All static and dynamic text must be translated. The UI must fully support Right-to-Left (RTL) layouts for Arabic.
2.  **Modern UI/UX:** The user has requested and overseen complete redesigns of key pages, including Financial Management, Message Center, Chat, File Gallery, Message Scheduling, and Notifications, to ensure a modern and aesthetically pleasing interface.
3.  **Role-Based Access Control (RBAC):** A critical feature is the implementation of permissions. Specifically, in the Financial Management section, administrators must be able to view all compound invoices, while residents should only see invoices related to their own units.
</product_requirements>
