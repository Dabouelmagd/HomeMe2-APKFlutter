## 🚀 Quick Start | بدء سريع

### 📥 التحميل | Download
```
1️⃣ Go to Releases → Download HomeMe-Desktop-v1.0.0-Portable.zip
2️⃣ Extract the ZIP file
3️⃣ Run Start-HomeMe.bat
```

## 🏗️ Technical Architecture

### Built With
- **Framework**: Electron 28.x
- **Frontend**: React + Modern UI
- **Backend**: FastAPI + Python
- **Database**: MongoDB (cloud-connected)
- **Languages**: JavaScript, Python
- **Packaging**: electron-builder

### App Structure
```
HomeMe-Desktop/
├── HomeMe.exe              # Main application
├── Start-HomeMe.bat       # Quick launcher
├── Setup-HomeMe.bat       # Installation wizard
├── README.txt             # User guide
└── resources/             # App resources
    ├── app.asar          # Application code
    └── node_modules/     # Dependencies
```
