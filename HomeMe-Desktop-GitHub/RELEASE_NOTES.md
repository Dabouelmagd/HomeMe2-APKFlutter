## 🔧 Technical Specifications

### System Requirements
| Component | Minimum | Recommended |
|-----------|---------|-------------|
| **Operating System** | Windows 10 x64 | Windows 11 x64 |
| **RAM** | 4 GB | 8 GB |
| **Storage** | 300 MB free space | 500 MB free space |
| **Internet** | Stable connection required | High-speed broadband |
| **Display** | 1024x768 | 1920x1080 or higher |

### Technology Stack
- **Framework**: Electron 28.x
- **Frontend**: React 18+ with modern hooks
- **Backend Integration**: FastAPI REST APIs
- **Database**: MongoDB (cloud-connected)
- **Packaging**: electron-builder
- **Security**: Context isolation, no Node integration

### Performance Metrics
- **Startup Time**: ~3-5 seconds
- **Memory Usage**: ~200-400 MB
- **CPU Usage**: <10% (idle), <30% (active)
- **Network**: Bandwidth depends on usage

## 🚀 Installation Guide

### Quick Start (Recommended)
```bash
1. Download: HomeMe-Desktop-v1.0.0-Portable.zip
2. Extract: Right-click → Extract All
3. Launch: Double-click Start-HomeMe.bat
4. Login: admin / admin123
```

### Full Installation
```bash
1. Download and extract the ZIP file
2. Right-click Setup-HomeMe.bat → Run as Administrator
3. Follow the installation wizard
4. Launch from Desktop or Start Menu
```

### Manual Launch
```bash
1. Extract ZIP file to any folder
2. Double-click HomeMe.exe
3. Application runs directly
```

## 🛠️ Troubleshooting

### Common Issues & Solutions

#### "Windows protected your PC"
```
Solution:
1. Click "More info"
2. Click "Run anyway"
3. Or: Right-click file → Properties → Unblock
```

#### Application won't start
```
Solution:
1. Ensure Windows 10/11 x64
2. Run as Administrator
3. Check internet connection
4. Disable antivirus temporarily
```

#### Connection errors
```
Solution:
1. Verify internet connection
2. Check firewall settings
3. Click "Retry" in the app
4. Restart the application
```

#### Language not displaying correctly
```
Solution:
1. Ensure proper fonts are installed
2. Check Windows language settings
3. Restart the application
4. Try different language and switch back
```
